Shoebill MIDI Sequencer

Shoebill is a terminal based, scriptable MIDI sequencer, made in C++. It has only been tested so far on Linux, though it should work on Windows. It's nowhere near as complex as a proper scripting/programming language, but you can get pretty creative with it. It has macros, randomization features, a host of useful functions, and the ability run multiple sequencers asynchronously, across shared scripts. I started it before LLMs became able to do these sorts of things (as you can probably tell from the messy code), so no AI/LLM had a hand in making it. A link to it's Github page can be found here.

jacobs-data-structures

This is my attempt to reteach myself DSA, since my college professor did a poor job. I'm making my own set of data structures and algorithms in C for use in my other projects. It's not particularly interesting, but I'm having fun working on it. Since the purpose of it is education, I have not used any AI/LLMs to help create it. In fact, it's been mostly constructed out of DSA books I have on hand. A link to it's Github page can be found here.

Random Noise Generators

I have created two random noise generators in Python, one for making Perlin noise and another that uses Wave Function Collapse to draw characters to the terminal, following a set of rules. Again, they were more for my education than for anything else, to learn the principles of random noise generation in case I needed it for any sort of procedural generation. Here are the links to the Perlin Noise Generator and the Wave Function Collapse Github pages. An LLM was used sparingly in these projects, mostly to explain how to use the numpy library to speed up the generation.
